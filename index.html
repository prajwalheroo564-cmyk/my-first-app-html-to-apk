My First App

Website → Android APK

Build your Android app

Enter a website you own or have permission to package. The cloud build workflow creates a test APK.

This first version converts hosted websites only. HTML/ZIP upload comes later.
Next step: This interface does not secretly send your data anywhere. After validating your inputs, it opens your GitHub Actions page. Enter the same app name and URL in the workflow's “Run workflow” form to build the APK.

Never paste a GitHub token or password into this page.

Builds run in GitHub Actions. APKs are debug-signed for testing.
